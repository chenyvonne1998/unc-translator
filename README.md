# Unc Translator

Translate slang into plain English, or describe what you mean and get the slang for it.

- **Slang → Meaning:** type `delulu` and get its meaning plus an example sentence.
- **Meaning → Slang:** hit ⇄, type `someone who is charming`, and get `Rizz`.
- 🎤 Speak your input, or have the result read aloud.

## Run it

No install needed. Open `index.html` in your browser, or:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Add more slang

Edit `slang-data.js`. See `CLAUDE.md` for the entry format.
